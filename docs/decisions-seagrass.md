# 决策记录：海草房 × 海草床（B 赛道 · 交互式网页）

> 记录时间：2026-11-19　截止：2026-11-19 24:00
> 用途：①锁定方案，避免中途跑偏；②直接复用为「作品说明」和「AI 创作说明」的素材。

## D1 赛道与形态
- B 赛道「蓝色数字传播」→ 交互式网页，单页滚动叙事，静态部署到 GitHub Pages。
- 理由：不用出镜、不用拍摄设备；5 件套（录屏 / 链接 / 源码 / 作品说明 / AI 说明）可在一天内交齐；"交互逻辑"天然好写。

## D2 选题
- 荣成 **海草房 × 海草床**：同一株大叶藻（鳗草），屋顶上是非遗，海底是"草原"。
- 理由：同时命中 B 赛道选题里的「海洋非遗活态传承」与「海洋生态保护」；山东本地性 + 跨文化纵深；避开"海洋塑料"这类评委看腻的同质化题材（创新项容易被压到 15 分档）。

## D3 语言策略
- 中文 + 英文承担**全文叙事**（人工校对）。
- 法、俄、日只出现**物种名与词源**，不承担全文翻译。
- 理由：文化传播价值占 25%，看的是"译介准确度、跨文化适配"；四语全文在 12 小时内必然机翻味，宁少勿滥。把多语种做成"名字墙"反而更点题"以语为桥"。

## D4 叙事内核
一株草，五种叫法，五种活法：
- 中文「大叶藻 / 鳗草 / 海带草」——按形态、按鱼、按用途（盖屋顶）；
- 英文「eelgrass」——鳗鱼的草，按栖息者；
- 法文「zostère」——希腊语"腰带"，按形态；
- 俄文「взморник」——"海边之物"，且晒干后作填充、包装材料；
- 日文「アマモ」。
转折：青岛、威海、烟台近岸 **超过 80% 海草床已完全消失**；荣成放流 110 万株、修复 1250 亩。
落点：屋顶要修、海底要种、名字要有人继续叫——三条行动线。

## D5 数据纪律
- 只用可溯源公开数据；页面设「数据来源」区，每条标机构 + 年份 + 链接。
- 不做无出处的"全球海草床每年消失 X%"式引用；不把"亩"混写成"公顷"。
- 图片只用 CC0 / CC BY 或纯代码生成，页面标注来源；不下载来源不明的网图。
