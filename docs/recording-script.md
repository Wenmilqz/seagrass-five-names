# 演示录屏脚本（1080p / 约 110 秒 / 中文字幕）

交互类作品要求“完整演示录屏”。录屏不是把页面从头滚到尾，而是**按叙事节奏演示交互**：滚动推进、数字出现、名字卡翻转、语言切换。

## 一、录制设置

- 浏览器窗口 1440×900，缩放 100%，F11 全屏，关掉书签栏和扩展图标。
- 录屏工具：Xbox Game Bar（Win+G）或 OBS；输出 1920×1080、30fps、MP4（H.264）。
- 鼠标移动慢，关键数字处停 1–2 秒；不要快速甩动。
- 先本地打开 `index.html` 录一遍，确认没有卡顿；正式录时网络断开也不影响。
- 录完在剪映 / Premiere 里加中文字幕（下方 SRT 可直接导入）。

## 三、字幕文件

同目录 `subtitles.srt` 可直接导入剪映 / Premiere。时间轴按 112 秒总长排；若你的录屏长度不同，整体拉伸即可。

## 四、剪辑注意

- 开头不要放 logo 动画，直接进页面；结尾停在行动页或封面上 2 秒。
- 字幕字号 ≥ 28px（1080p 下），白字黑边或半透明底，别用花字。
- 导出：H.264、MP4、1920×1080、码率 8–12 Mbps。
- 文件名：`B赛道+队长姓名+海草房与海草床.mp4`。

## 五、如果时间不够

只录 60 秒也行：封面 → 80% → 名字卡 2 张 → 修复数字 → 行动页。**五项材料齐全**比视频精致更重要。
